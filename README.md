## ⚡ What I build

- 🧱 **Full-stack Laravel apps**: multi-role platforms, Filament admin panels, Sanctum-secured REST APIs, Vue and React front-ends
- 💳 **Payments and fintech**: Stripe and Paystack checkouts, escrow flows, billing portals, currency exchange
- 🛒 **E-commerce**: WooCommerce and custom Laravel stores, online ordering, gift card platforms
- 🎓 **Platforms**: LMS and e-learning, marketplaces, booking systems, influencer marketing
- 🤖 **AI and automation**: chatbots, WhatsApp Business API, workflow automation
- 🌐 **WordPress**: fast, SEO-ready business sites, custom themes and plugins

## 🚢 How I ship

- ✅ **Tested**: feature tests with Pest on my Laravel builds
- 🔁 **Automated**: GitHub Actions CI/CD, so a push to `main` tests and deploys
- 🐳 **Containerised**: Docker for consistent local and production environments
- ☁️ **Hosted right**: AWS (EC2, S3) and hardened Linux/Nginx servers
- 🔐 **Secure by default**: role-based access, hardened auth, verified payment webhooks
